## Getting Started

### Creating an Account

1. Visit the XBoard website
2. Click "Register" or "Sign Up"
3. Fill in registration form:
   - Email address
   - Password (minimum 8 characters)
   - Confirm password
   - Invite code (if required)
4. Click "Register"
5. Check your email for verification link (if required)
6. Click verification link to activate account

### Logging In

1. Visit the XBoard website
2. Click "Login"
3. Enter your email and password
4. Click "Login" to access your dashboard

### Forgot Password

1. Click "Forgot Password" on login page
2. Enter your email address
3. Click "Send Reset Link"
4. Check your email for reset instructions
5. Click link in email
6. Enter new password
7. Click "Reset Password"

## Account Management

### Dashboard Overview

After logging in, your dashboard shows:

- **Subscription Status**: Current plan and expiration
- **Traffic Usage**: Data used and remaining
- **Account Balance**: Available funds
- **Commission Earnings**: Referral rewards
- **Recent Orders**: Purchase history
- **Announcements**: Important notices


### Account Settings

#### Updating Profile

1. Click your profile icon
2. Select "Settings"
3. Update information:
   - Email address
   - Display name
   - Notification preferences
4. Click "Save Changes"

#### Changing Password

1. Go to Settings > Security
2. Enter current password
3. Enter new password
4. Confirm new password
5. Click "Change Password"

#### Managing Sessions

View and manage active sessions:

1. Go to Settings > Sessions
2. See list of active devices:
   - Device type
   - Location
   - Last active time
3. Click "Revoke" to log out a device

## Subscription Plans

### Viewing Available Plans

1. Navigate to "Plans" or "Subscribe"
2. Browse available subscription plans
3. Each plan shows:
   - Monthly price
   - Traffic quota
   - Speed limit
   - Device limit
   - Available servers

### Choosing a Plan

Consider these factors:

- **Traffic Needs**: How much data you'll use monthly
- **Speed Requirements**: Streaming needs higher speeds
- **Device Count**: How many devices you'll connect
- **Duration**: Longer subscriptions often have discounts

### Purchasing a Plan

1. Click "Subscribe" on desired plan
2. Select subscription duration:
   - Monthly
   - Quarterly
   - Half-yearly
   - Yearly
   - Two-year
   - Three-year
3. Review order summary
4. Apply coupon code (if available)
5. Click "Proceed to Payment"

### Renewing Subscription

#### Manual Renewal

1. Go to Dashboard
2. Click "Renew Subscription"
3. Select duration
4. Complete payment

#### Auto-Renewal

If enabled:
- Subscription renews automatically
- Payment charged before expiration
- Receive email notification
- Can disable in settings

## Setting Up Your Connection

### Getting Your Subscription Link

1. Navigate to "Subscription" page
2. Find your unique subscription link
3. Click "Copy" button to copy link

### QR Code

For mobile devices:
1. View QR code on Subscription page
2. Scan with your proxy client app
3. Configuration imports automatically

### Manual Configuration

If needed, view manual configuration:
1. Go to Subscription page
2. Click "Show Configuration"
3. Copy server details:
   - Server address
   - Port
   - Password/UUID
   - Encryption method

### Supported Clients

#### Windows
- **Clash for Windows**: Recommended
- **V2RayN**: Alternative option
- **Shadowsocks**: For Shadowsocks protocol

#### macOS
- **ClashX**: Recommended
- **V2RayU**: Alternative option
- **Shadowsocks**: For Shadowsocks protocol

#### iOS
- **Shadowrocket**: Recommended (paid)
- **Quantumult X**: Advanced features (paid)
- **Surge**: Professional option (paid)

#### Android
- **Clash for Android**: Recommended
- **V2RayNG**: Alternative option
- **Shadowsocks**: For Shadowsocks protocol

### Client Setup Instructions

#### Clash (Windows/macOS/Android)

1. Download and install Clash client
2. Open Clash
3. Click "Profiles" or "Configuration"
4. Click "Import from URL"
5. Paste your subscription link
6. Click "Download"
7. Select imported profile
8. Click "Start" or enable proxy
9. Choose proxy mode (Rule/Global/Direct)

#### Shadowrocket (iOS)

1. Download Shadowrocket from App Store
2. Open app
3. Tap "+" button
4. Select "Type" > "Subscribe"
5. Paste subscription link in URL field
6. Tap "Done"
7. Tap subscription to download servers
8. Toggle switch to connect

### Resetting Subscription Secret

If your link is compromised:

1. Go to Subscription page
2. Click "Reset Secret"
3. Confirm action
4. New link generated
5. Update all your devices with new link

**Note**: Old link stops working immediately

## FAQ

### Account Questions

**Q: How do I change my email address?**  
A: Go to Settings > Profile, update email, verify new address via email link.

**Q: Can I use multiple devices?**  
A: Yes, up to your plan's device limit. Check plan details for specific limit.

**Q: How do I delete my account?**  
A: Contact support to request account deletion. Active subscriptions must be cancelled first.

### Subscription Questions

**Q: When does my subscription expire?**  
A: Check Dashboard for expiration date. You'll receive email reminders before expiration.

**Q: Can I upgrade my plan?**  
A: Yes, purchase new plan. Unused time from current plan may be credited.

**Q: What happens when my subscription expires?**  
A: Service stops immediately. Renew to restore access. Data is retained for 30 days.

**Q: Can I get a refund?**  
A: Refund policy varies. Contact support within 7 days of purchase for refund requests.

### Connection Questions

**Q: Why can't I connect?**  
A: Check:
- Subscription is active
- Client is configured correctly
- Subscription link is current
- Internet connection is working

**Q: Connection is slow. What should I do?**  
A: Try:
- Switch to different server
- Check local internet speed
- Update client software
- Contact support if issue persists

**Q: Can I use on multiple devices simultaneously?**  
A: Yes, up to your plan's device limit. Exceeding limit may disconnect oldest connection.

### Traffic Questions

**Q: How is traffic calculated?**  
A: Both upload and download count toward quota. Some servers may have rate multipliers.

**Q: When does traffic reset?**  
A: Usually monthly or on subscription renewal. Check Dashboard for reset date.

**Q: What happens if I run out of traffic?**  
A: Service stops until traffic resets or you purchase additional traffic.

**Q: Can I purchase extra traffic?**  
A: Yes, go to Dashboard and click "Buy Traffic" to purchase additional quota.

### Payment Questions

**Q: What payment methods are accepted?**  
A: Credit cards, PayPal, cryptocurrency, and regional payment methods. See checkout for options.

**Q: Is my payment information secure?**  
A: Yes, payments processed through secure gateways. We don't store card details.

**Q: Can I use account balance for payments?**  
A: Yes, add funds to balance and select it as payment method during checkout.

**Q: How do I get an invoice?**  
A: Go to Orders, click on order, and download invoice.

### Referral Questions

**Q: How much commission do I earn?**  
A: Commission rate varies. Check Referral page for current rate.

**Q: When do I receive commissions?**  
A: After referred user's payment is confirmed. Usually within 24 hours.

**Q: Can I withdraw commissions?**  
A: Yes, transfer to account balance and use for subscriptions or withdraw (if supported).

**Q: Is there a limit to referrals?**  
A: No limit. Refer as many users as you want.

### Technical Questions

**Q: Which client should I use?**  
A: Clash recommended for most users. See "Supported Clients" section for options.

**Q: How do I update my subscription in client?**  
A: Most clients auto-update. Or manually update subscription in client settings.

**Q: Can I use on router?**  
A: Yes, if router supports proxy protocols. Configuration varies by router model.

**Q: Does it work in my country?**  
A: Service works globally. Some countries may have restrictions. Check local laws.

## Troubleshooting

### Common Issues

**Issue: Can't log in**
- Verify email and password
- Check caps lock
- Reset password if forgotten
- Clear browser cache
- Try different browser

**Issue: Subscription link not working**
- Copy link carefully (no extra spaces)
- Check subscription is active
- Try resetting subscription secret
- Update client software

**Issue: No servers showing in client**
- Update subscription in client
- Check internet connection
- Verify subscription link is correct
- Try reimporting subscription

**Issue: Connection drops frequently**
- Switch to different server
- Check internet stability
- Update client software
- Disable battery optimization (mobile)

**Issue: Payment failed**
- Verify payment details
- Check card has sufficient funds
- Try different payment method
- Contact payment provider
- Contact support if issue persists
