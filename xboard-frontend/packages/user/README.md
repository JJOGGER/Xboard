# XBoard User Portal

Customer-facing website for XBoard proxy panel.

## Tech Stack

- Vue 3 with Composition API
- TypeScript
- Vite
- Naive UI
- Vue Router
- Pinia
- TailwindCSS

## Development

```bash
# Install dependencies
pnpm install

# Start dev server
pnpm dev

# Build for production
pnpm build

# Run tests
pnpm test

# Lint code
pnpm lint
```

## Project Structure

```
src/
├── assets/       # Static assets
├── components/   # Reusable components
├── composables/  # Composition API composables
├── layouts/      # Layout components
├── pages/        # Page components
├── router/       # Vue Router configuration
├── stores/       # Pinia stores
├── styles/       # Global styles
├── App.vue       # Root component
└── main.ts       # Entry point
```
