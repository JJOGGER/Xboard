## Quick Start

### Development
```bash
# Start admin development server (http://localhost:3000)
pnpm dev:admin

# Start user development server (http://localhost:3001)
pnpm dev:user
```

### Building
```bash
# Build both applications
pnpm build

# Build individually
pnpm build:admin
pnpm build:user
```

### Testing
```bash
# Run all tests
pnpm test

# Run specific test types
pnpm test:unit
pnpm test:property
pnpm test:e2e
```

### Code Quality
```bash
# Lint all packages
pnpm lint

pnpm format
```
