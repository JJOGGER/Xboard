# 数据库持久化问题已修复 ✅

## 问题描述

你反馈说"每次运行账号就都丢失了"。

## 问题原因

之前开发数据库和测试数据库使用的是**同一个文件**：
- 开发环境 (`.env`): `database/database.sqlite`
- 测试环境 (`phpunit.xml`): `database/database.sqlite` ❌

当运行测试时，Laravel 的 `RefreshDatabase` 会完全清空并重建数据库，导致你的管理员账号被删除。

## 解决方案

现在已经分离了开发数据库和测试数据库：
- **开发数据库**: `database/database.sqlite` ✅ 持久化保存
- **测试数据库**: `database/testing.sqlite` ✅ 仅用于测试

## 修改内容

### 1. 更新了 `phpunit.xml`
```xml
<env name="DB_DATABASE" value="database/testing.sqlite"/>
```

### 2. 创建了独立的测试数据库
```bash
touch database/testing.sqlite
```

### 3. 更新了 `.gitignore`
添加了数据库文件忽略规则，防止提交到 Git。

## 数据库文件说明

| 文件 | 用途 | 是否持久化 |
|------|------|-----------|
| `database/database.sqlite` | 开发环境 | ✅ 是 |
| `database/testing.sqlite` | 测试环境 | ❌ 否（每次测试重置） |

## 重要提示

1. ✅ **不要删除** `database/database.sqlite` - 这是你的开发数据库
2. ✅ **可以删除** `database/testing.sqlite` - 测试时会自动重建
3. ✅ **定期备份** `database/database.sqlite`：
   ```bash
   cp database/database.sqlite database/database.sqlite.backup
   ```
