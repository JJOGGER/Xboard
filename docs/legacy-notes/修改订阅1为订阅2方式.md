## nameserver-policy 配置说明

### 常用规则

1. **`geosite:cn`** - 中国网站
2. **`geosite:gfw`** - 被墙网站
3. **`geosite:geolocation-!cn`** - 非中国网站
4. **`geosite:private`** - 私有网络
5. **`geosite:apple`** - Apple 服务

### 推荐的 DNS 服务器

**国内 DNS**（用于中国网站）:
- `https://doh.pub/dns-query`
- `https://dns.alidns.com/dns-query`
- `https://223.5.5.5/dns-query`
- `https://223.6.6.6/dns-query`

**国外 DNS**（用于被墙网站和非中国网站）:
- `https://cloudflare-dns.com/dns-query`
- `https://dns.google/dns-query`
- `tls://1.1.1.1:853`
- `tls://8.8.8.8:853`

### 完整配置示例

```yaml
nameserver-policy:
  # 中国网站、私有网络、Apple 服务使用国内 DNS
  "geosite:cn,private,apple":
    - https://doh.pub/dns-query
    - https://dns.alidns.com/dns-query
    - https://223.5.5.5/dns-query
  
  # 被墙网站使用国外 DNS
  "geosite:gfw":
    - https://cloudflare-dns.com/dns-query
    - https://dns.google/dns-query
  
  # 非中国网站使用国外 DNS
  "geosite:geolocation-!cn":
    - https://cloudflare-dns.com/dns-query
    - https://dns.google/dns-query
  
  # 广告域名直接拒绝
  "geosite:category-ads-all": rcode://success
  
  # 特定域名使用特定 DNS
  "www.baidu.com,+.google.cn":
    - 223.5.5.5
    - https://dns.alidns.com/dns-query
```

## 验证修改

修改后，可以通过以下方式验证：

1. **获取订阅链接**（使用 Clash Meta 客户端）
2. **查看订阅内容**，确认：
   - `dns.fallback` 为空列表 `[]`
   - `dns.nameserver-policy` 存在且配置正确
3. **导入到 Clash Meta For Android**，确认：
   - ✅ 不再出现 EOF 错误
   - ✅ 仍然支持智能 DNS 选择
   - ✅ 中国网站使用国内 DNS
   - ✅ 被墙网站使用国外 DNS

## 注意事项

1. **YAML 格式**: 确保修改后的 YAML 格式正确，缩进要一致
2. **备份**: 修改前建议备份原始配置
3. **测试**: 修改后建议先测试一个订阅链接，确认无误后再应用到生产环境
4. **GeoSite 数据库**: `nameserver-policy` 使用 `geosite:` 规则时，需要 GeoSite 数据库，但：
   - GeoSite 数据库通常已打包在应用中
   - 或者可以从可访问的地址下载（不像 GeoIP 那样被墙）
