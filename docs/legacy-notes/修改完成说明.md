## nameserver-policy 配置说明

### 规则说明

1. **`geosite:cn,private,apple`**
   - 中国网站、私有网络、Apple 服务
   - 使用国内 DNS（`doh.pub`、`dns.alidns.com`、`223.5.5.5`）

2. **`geosite:gfw`**
   - 被墙网站
   - 使用国外 DNS（`cloudflare-dns.com`、`dns.google`）

3. **`geosite:geolocation-!cn`**
   - 非中国网站
   - 使用国外 DNS（`cloudflare-dns.com`、`dns.google`）

### 工作流程

1. **查询域名时**：
   - 首先检查 `nameserver-policy` 是否匹配
   - 如果匹配，直接使用指定的 DNS 服务器
   - 如果不匹配，使用默认的 `nameserver`

2. **示例**：
   - 查询 `baidu.com` → 匹配 `geosite:cn` → 使用国内 DNS
   - 查询 `google.com` → 匹配 `geosite:gfw` → 使用国外 DNS
   - 查询 `github.com` → 匹配 `geosite:geolocation-!cn` → 使用国外 DNS

## 注意事项

1. **GeoSite 数据库**
   - `nameserver-policy` 使用 `geosite:` 规则时需要 GeoSite 数据库
   - GeoSite 数据库通常已打包在 Clash Meta For Android 应用中
   - 如果应用中没有，可能需要下载，但下载地址通常可访问（不像 GeoIP 那样被墙）

2. **自定义模板**
   - 如果用户使用自定义模板，代码中的保护机制会确保移除 fallback
   - 如果自定义模板中没有 nameserver-policy，会自动添加默认配置

3. **向后兼容**
   - 修改后的配置向后兼容
   - 不会影响现有功能
   - 只是改变了 DNS 选择机制
