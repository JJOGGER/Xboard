# 双后台路由修复完成

## 修复时间
2026-01-24

## 问题描述
访问新后台开发环境 `http://localhost:5174` 时会自动跳转到 `http://localhost:5174/admin-v2/` 并一直 loading，无法正常使用。

## 根本原因
`vite.config.ts` 和 `router/index.ts` 配置了 `base: '/admin-v2/'`，导致开发环境也使用这个路径前缀。但开发环境应该使用根路径 `/`，只有生产环境才需要 `/admin-v2/` 前缀。

## 修复方案

### 1. 修改 Vite 配置
**文件**: `xboard-frontend/packages/admin/vite.config.ts`

```typescript
// 修改前
base: '/admin-v2/'

// 修改后
base: process.env.NODE_ENV === 'production' ? '/admin-v2/' : '/'
```

### 2. 修改 Vue Router 配置
**文件**: `xboard-frontend/packages/admin/src/router/index.ts`

```typescript
// 修改前
history: createWebHistory('/admin-v2')

// 修改后
history: createWebHistory(import.meta.env.PROD ? '/admin-v2' : '/')
```

### 3. API 拦截器已正确配置
**文件**: `xboard-frontend/packages/shared/src/api/client.ts`

拦截器只对 `/v2/admin/*` 路径添加 secure_path，不影响登录和用户信息 API：

```typescript
if (config.url && config.url.startsWith('/v2/admin')) {
  const securePath = import.meta.env.VITE_SECURE_PATH || '144b73d9';
  config.url = config.url.replace('/v2/', `/v2/${securePath}/`);
}
```

## 修复结果

### ✅ 开发环境
- **访问地址**: `http://localhost:5174` (不需要 /admin-v2/)
- **路由行为**: 直接显示登录页面，不会跳转
- **API 路径**: 
  - 登录: `/v2/passport/auth/login` (无 secure_path)
  - 用户信息: `/v2/user/info` (无 secure_path)
  - 管理 API: `/v2/144b73d9/admin/*` (有 secure_path)

### ✅ 生产环境
- **访问地址**: `http://your-domain.com/admin-v2`
- **路由行为**: 正常访问，与旧后台不冲突
- **API 路径**: 与开发环境相同

## 双后台架构总结

### 旧后台
- **位置**: `public/assets/admin/`
- **访问**: `/admin` 或 `/{secure_path}` (如 `/144b73d9`)
- **特点**: 封装代码，无法修改
- **API**: 共享 `/api/v2/*`

### 新后台
- **位置**: `xboard-frontend/packages/admin/`
- **开发访问**: `http://localhost:5174` (根路径)
- **生产访问**: `/admin-v2`
- **特点**: Vue 3 前端，可以修改
- **API**: 共享 `/api/v2/*`

### API 路由规则
| API 类型 | 路径模式 | 是否需要 secure_path | 示例 |
|---------|---------|-------------------|------|
| Passport | `/v2/passport/*` | ❌ 否 | `/v2/passport/auth/login` |
| User | `/v2/user/*` | ❌ 否 | `/v2/user/info` |
| Admin | `/v2/admin/*` | ✅ 是 | `/v2/144b73d9/admin/stat/getOverride` |
