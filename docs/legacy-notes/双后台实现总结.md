## 🔄 回滚方案

如果需要回滚，非常简单:

```bash
# 删除新后台静态文件
rm -rf public/admin-v2

# 可选: 注释掉 routes/web.php 中的 admin-v2 路由组
```

旧后台完全不受影响，继续正常工作。
