# 新后台登录修复完成 ✅

## 问题

登录时报错：
```
❌ POST /api/v2/144b73d9/admin/passport/auth/login - Network error
```

## 原因

我之前的修复把**所有** V2 API 都加了 `secure_path`，但实际上：
- ✅ 管理 API 需要 secure_path: `/api/v2/{secure_path}/admin/*`
- ❌ 认证 API 不需要 secure_path: `/api/v2/passport/*`

## 已修复

修改了 `xboard-frontend/packages/shared/src/api/client.ts`，现在只对 **admin** 路径添加 `secure_path`：

```typescript
// 只对非 passport 的 V2 API 添加 secure_path
if (config.url && /^\/v2\/(?!passport)/.test(config.url)) {
  const securePath = import.meta.env.VITE_SECURE_PATH || '144b73d9';
  config.url = config.url.replace('/v2/', `/v2/${securePath}/`);
}
```

## API 路径对照表

| API 类型 | 原始路径 | 实际请求路径 | 说明 |
|---------|---------|------------|------|
| 登录 | `/v2/passport/auth/login` | `/v2/passport/auth/login` | ✅ 不加 secure_path |
| 登出 | `/v2/passport/auth/logout` | `/v2/passport/auth/logout` | ✅ 不加 secure_path |
| 统计 | `/v2/admin/stat/getOverride` | `/v2/144b73d9/admin/stat/getOverride` | ✅ 加 secure_path |
| 用户列表 | `/v2/admin/user/fetch` | `/v2/144b73d9/admin/user/fetch` | ✅ 加 secure_path |
| 订单列表 | `/v2/admin/order/fetch` | `/v2/144b73d9/admin/order/fetch` | ✅ 加 secure_path |
