```bash
VITE_SESSION_TIMEOUT=3600000
```

**重要**: `VITE_SECURE_PATH` 必须与后端的 `secure_path` 设置一致（在 `.env` 文件中）

## 常见问题

### Q1: 访问 localhost:5174 还是跳转到 /admin-v2/
**A**: 清除浏览器缓存并重启前端服务:
```bash
cd xboard-frontend
npm run dev:admin
```

### Q2: 登录后报 404 错误
**A**: 检查 `.env.local` 中的 `VITE_SECURE_PATH` 是否与后端 `.env` 中的 `secure_path` 一致

### Q3: CORS 跨域错误
**A**: 确保后端 `config/cors.php` 配置正确:
```php
'allowed_origins' => [
    'http://localhost:5173',
    'http://localhost:5174',
    // ...
],
'supports_credentials' => true,
```

## 架构说明

### 双后台系统
- **旧后台**: 封装代码，无法修改，通过 `/admin` 或 `/{secure_path}` 访问
- **新后台**: Vue 3 前端，可以修改，开发环境通过 `/` 访问，生产环境通过 `/admin-v2` 访问
- **共享 API**: 两个后台共享相同的 V2 API (`/api/v2/*`)

### API 路由规则
1. **Passport API** (`/v2/passport/*`): 不需要 secure_path
2. **User API** (`/v2/user/*`): 不需要 secure_path
3. **Admin API** (`/v2/admin/*`): 需要 secure_path，自动转换为 `/v2/{secure_path}/admin/*`
