## 遇到的问题及解决

### 问题 1: 旧后台登录失败 ✅

**原因**: 错误地修改了 V2 API 路由，给 Passport 路由添加了 `secure_path` 前缀

**解决**: 回滚了以下文件：
- `app/Http/Routes/V2/PassportRoute.php`
- `app/Http/Routes/V2/UserRoute.php`
- `app/Http/Routes/V2/AdminRoute.php`

### 问题 2: 旧后台 plan/fetch 500 错误 ✅

**原因**: `app/Models/Plan.php` 中 `capacity_limit` 字段没有定义类型转换，导致字符串和整数运算错误

**解决**: 在 `$casts` 中添加：
```php
'capacity_limit' => 'integer',
'device_limit' => 'integer',
'sell' => 'boolean',
```

### 问题 3: 避免影响旧后台 ✅

**原因**: 初始配置时修改了太多不相关的文件

**解决**: 回滚了所有可能影响旧后台的修改：
- 模型文件（User, ServerGroup）
- 控制器文件（CommController, UserController）
- 服务提供者（RouteServiceProvider）
- 协议文件（ClashMeta）
- 定时任务（Kernel）

## 部署新后台

### 自动部署（推荐）

```bash

```

### 手动部署

```bash
# 1. 构建前端
cd xboard-frontend
npm run build:admin

# 2. 部署到 public 目录
cd ..
rm -rf public/admin-v2
mkdir -p public/admin-v2
cp -r xboard-frontend/packages/admin/dist/* public/admin-v2/

# 3. 设置权限
chmod -R 755 public/admin-v2
```
