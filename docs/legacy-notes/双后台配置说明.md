## ✅ 配置完成

**完成时间**: 2026-01-24

## 系统架构

### 旧后台（封装代码，无法修改）
- **位置**: `public/assets/admin/` 
- **视图**: `resources/views/admin.blade.php`
- **访问路径**: `http://your-domain.com/admin` 或 `/{secure_path}`
- **API**: `/api/v2/*` (与新后台共享)
- **特点**: 封装的前端代码，无法修改源码

### 新后台（Vue 3，可以修改）
- **位置**: `xboard-frontend/packages/admin/`
- **视图**: `resources/views/admin-v2.blade.php`
- **访问路径**: `http://your-domain.com/admin-v2`
- **API**: `/api/v2/*` (与旧后台共享)
- **特点**: Vue 3 + TypeScript，完全可控

## 已完成的配置

### 1. 前端配置 ✅

**文件**: `xboard-frontend/packages/admin/vite.config.ts`
```typescript
export default defineConfig({
  base: '/admin-v2/', // 新后台使用 /admin-v2 路径
  // ...
})
```

**文件**: `xboard-frontend/packages/admin/src/router/index.ts`
```typescript
const router = createRouter({
  history: createWebHistory('/admin-v2'), // 路由基于 /admin-v2
  routes
})
```

### 2. 后端配置 ✅

**文件**: `routes/web.php`
```php
// 旧后台路由 (已存在，保持不变)
Route::get('/{secure_path}', function () {
    return view('admin', [...]);
});

// 新后台路由 (新增)
Route::prefix('admin-v2')->group(function () {
    Route::get('/{any?}', function () {
        return view('admin-v2', [...]);
    })->where('any', '.*');
});
```

### 3. 视图文件 ✅

**文件**: `resources/views/admin-v2.blade.php` (新建)
- 为新后台提供 HTML 入口
- 加载 `/admin-v2/assets/` 下的静态资源

### 4. 部署脚本 ✅

**文件**: `deploy-admin-v2.sh` (新建)
- 自动构建 Vue 3 前端
- 自动部署到 `public/admin-v2/`

## 部署步骤

### 方式 1: 自动部署（推荐）

```bash
./deploy-admin-v2.sh
```

### 方式 2: 手动部署

```bash
# 1. 构建前端
cd xboard-frontend
npm run build:admin

# 2. 部署到 public 目录
cd ..
rm -rf public/admin-v2
mkdir -p public/admin-v2
cp -r xboard-frontend/packages/admin/dist/* public/admin-v2/

# 3. 设置权限
chmod -R 755 public/admin-v2
```

## 共享的资源

### ✅ 两个后台共享
- 相同的 Laravel 后端
- 相同的 API (`/api/v2/*`)
- 相同的数据库
- 相同的用户认证
- 相同的会话管理

### ❌ 两个后台独立
- 不同的前端代码
- 不同的访问路径
- 不同的静态资源
- 不同的视图文件

## 优势

1. **旧后台继续工作**: 封装代码保持不变，零风险
2. **新后台可扩展**: Vue 3 代码完全可控，可以添加新功能
3. **平滑过渡**: 用户可以选择使用哪个版本
4. **共享 API**: 不需要维护两套后端代码
5. **独立部署**: 新后台的更新不影响旧后台

## 故障排除

### 新后台 404
```bash
# 重新部署
./deploy-admin-v2.sh

# 检查文件
ls -la public/admin-v2/
```

### 静态资源 404
```bash
# 检查配置
grep "base:" xboard-frontend/packages/admin/vite.config.ts
grep "createWebHistory" xboard-frontend/packages/admin/src/router/index.ts
```

### API 调用失败
```bash
# 查看日志
tail -f storage/logs/laravel.log
```

## 回滚方案

如果需要回滚新后台：

```bash
# 删除新后台静态文件
rm -rf public/admin-v2

# 可选：注释掉 routes/web.php 中的 admin-v2 路由
```

旧后台完全不受影响。
